# WETT DIGITAL — We Thrive Together

## Current state
Version 4 visual storefront prototype (single-file HTML at `index.html`). Kept on `wett-digital-preview` to avoid changing the existing WETT website.

## Local preview
Download `index.html` and open in a browser. Graphics, CSS and JavaScript are embedded.

## Working prototype features
- Responsive cinematic-style landing page and logo
- Six service categories and four storefront callouts
- Interactive three-step project builder
- Inquiry summary, copy/save brief, and preferred consultation date

## Not yet live or integrated
- No real payment processor, checkout, or customer/order database
- Consultation dates are requests, not confirmed reservations
- No connected email delivery API or verified intake endpoint
- Portfolio illustrations are concept art, not verified actual project photographs
- No full deployed browser QA, accessibility audit, or performance test

## Before launch
1. Connect independent Vercel preview project (requires authorization for team `wettentllcs-projects`). Set root directory to `wett-digital`.
2. Review all service descriptions and supply official business contact email.
3. Source and approve authentic portfolio screenshots, logos and ownership/usage permissions.
4. Add secure hosted intake endpoint with spam protection, validation and privacy policy.
5. Add calendar availability integration with email confirmations.
6. Agree pricing, scope, policies, and payments integration; verify test transactions.
7. Test browser journeys, mobile layouts, reduced motion, accessibility, and SEO.

Do not deploy the preview branch over the main WETT website without explicit approval.
